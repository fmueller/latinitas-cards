# LatinitasCards v0.4.0

## Summary

Planned release. Adds corpus-first card generation for arbitrary Latin texts, guided
translation practice, ranked card budgets, TEI ingestion, and English generated content.
An existing Anki deck is no longer required, though corpus cards can link to lexical entries
created by deck-first workflows.

## Goals

- Generate useful cards directly from structured Latin corpora.
- Support reading and translation practice without exact-string grading.
- Select a manageable set of high-value cards without requiring exhaustive manual review.
- Validate the normalized model beyond USFX with scholarly TEI material.

## Potential Features

### Corpus-First Projects

Create a project from one or more normalized corpora without an existing deck. Corpus-first
notes receive stable identities from corpus passage identity, recipe identity, semantic
exercise key, and target language where it changes the exercise. A later lexical link does
not change an existing context card's identity.

### Context And Translation Recipes

Support distinct pedagogical recipes rather than one universal corpus card:

- contextual lexical recognition;
- guided grammatical analysis followed by translation;
- short phrase translation; and
- free sentence translation followed by a reference and self-assessment.

The default context is one sentence while preserving the full source segment and citation.
Exact German or English string matching is not used to grade translations. Reference
translations may come from parallel corpora, user input, or reviewed generated annotations.

### Ranked Card Budgets

Rank valid candidates using transparent factors such as assigned reading, target forms,
analysis confidence, sentence length, unknown-word count, near-duplicate suppression, and
exercise diversity. Project profiles set budgets per recipe, source, or run. Selection is
deterministic, stores score reasons, and retains unselected candidates in a machine-readable
report rather than demanding review of every candidate.

### TEI XML Adapter

Import a documented, tested subset of TEI XML into the normalized JSONL model, preserving
edition/source metadata and source-native citations. Unsupported constructs fail or warn
explicitly. TEI variation is handled by adapter profiles rather than leaking format-specific
branches into card recipes.

### German And English Output

Generated content supports German and English through explicit language tags. German
remains the initial/default configured target language; English is added without changing
the CLI control language or hard-coding language-specific fields into domain models. Other
target languages remain extension points, not release requirements.

## Caution

- A ranked budget can hide useful candidates unless rejected/unselected reasons remain
  inspectable.
- Reference translations are not uniquely correct and must be presented as guidance.
- TEI is a family of practices, not one uniform schema.
- Corpus-first lexical inference can be ambiguous without a reviewed lexicon or deck link.

## Recommendation About LLM Support

An LLM may draft translations, explanations, or rankings, but generated facts retain
provenance and review state. LLM grading is optional and never replaces self-assessment or
reviewed references. Deterministic ranking remains available offline.

## Explicitly Excluded

- Comprehensive support for every TEI customization.
- Automatic syntax-role coloring.
- A built-in dictionary dataset.
- More output languages than German and English.
- Direct Anki integration as the required workflow.
