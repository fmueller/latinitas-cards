# LatinitasCards v0.5.0

## Summary

Planned release. Expands the exercise library from principal parts and form parsing into
reviewed grammar, syntax, paradigms, and mnemonic content, with separate configurable color
layers for morphology and sentence function.

## Goals

- Practice the grammatical knowledge needed to translate Latin texts.
- Represent uncertainty and alternate analyses instead of teaching guesses as facts.
- Support course-specific color conventions without naming or hard-coding one course.
- Treat mnemonics as curated content that can generate repeatable cards.

## Potential Features

### Grammar Exercise Library

Add recipe families for verb production/recognition, stems, noun nominative/genitive pairs,
declension recognition, case and number, adjective agreement, and selected grammatical
constructions. Each card has one primary learning objective. The profile suggests compatible
recipes, the user confirms them, and saved selection remains deterministic.

### Curated Grammar And Mnemonics

Define a human-readable content format for rules, examples, tags, target language, and
mnemonics. LatinitasCards may generate forward, reverse, cloze, or example cards from
reviewed content. LLMs may draft suggestions, but runtime invention is not accepted as
authoritative course material.

### Reviewed Syntax Roles

Annotate configurable sentence functions such as subject, predicate, object, attribute,
and construction-specific roles. Automatic parsers and agents propose analyses with
alternatives and provenance. Only calibrated, policy-approved claims bypass review; syntax
remains independently reviewable from morphology and translation.

### Semantic Color Layers

Render morphology and sentence-function annotations as independent semantic classes. Theme
profiles map roles to colors plus non-color cues and support light/dark modes. Changing a
theme never changes linguistic data or generated-note identity. Cards may enable either
layer or both according to their recipe.

### Domain-Specific Confidence Calibration

Calibrate analyzers separately by claim type, recipe, and material domain such as classical,
biblical, or medieval Latin. Reviewed samples establish auto-accept thresholds. Store
categorical states such as verified, auto-accepted, review-required, rejected, and
unassessed rather than presenting uncalibrated decimal scores as truth.

## Caution

- Grammar conventions and terminology vary; profiles must name roles and sources.
- Incorrect study-card facts are more harmful than incomplete coverage.
- Dependency parses do not directly guarantee correct pedagogical sentence functions.
- Colors must not become the only carrier of meaning.

## Recommendation About LLM Support

Use optional LLMs for candidate analyses, explanations, and mnemonic drafts under the same
calibration, provenance, and review policy as other analyzers. Never use self-reported model
confidence as an automation threshold.

## Explicitly Excluded

- Fully automatic authoritative syntax analysis for arbitrary Latin.
- Automatic acceptance of generated mnemonics.
- A GUI grammar editor.
- Exhaustive coverage of Latin grammar.
- Required direct Anki integration.
