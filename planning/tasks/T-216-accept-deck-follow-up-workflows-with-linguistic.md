# T-216-accept-deck-follow-up-workflows-with-linguistic Accept deck follow-up workflows with linguistic and native evidence

## Description

Own independent whole-spec linguistic/native acceptance for all eight requests on
one exact candidate. Use disposable Linux Anki Desktop and redistributable fixtures;
private collection runs require separate access/permission.

## Acceptance

- Trace every spec acceptance clause to executed scenario, expected result, source/
  config/candidate revision and evidence. Independently judge linguistic/calibration
  outcomes against approved criteria. Failed/unavailable is failed/not evaluable.
- Execute mixed source → setup → review/calibrate → preview → generate → reference
  setup → native import → rename/re-export/update. Exactly 10 accepts/2 rejects leave
  other rows open; PPP/supine/missing/future controls hold. Valid reviewed state
  survives rename; changed evidence invalidates applicable decisions only.
- Verify nominal template additions without renumbering verb cards, retained fields/
  identities and actual scheduling/history before/after import/update. Exercise old/
  custom CSS and explicit migrations, never production collection mutations.
- Install calibration-accepted card, withdraw calibration/reference, regenerate and
  execute installed-identity handoff plus supported managed/manual resolution. Old
  acceptance is not asserted; omission is not repair; history/scheduling survive.
- Inspect default/hidden/neutral/mixed morphology in German/English light/dark with
  accessible disclosures and no front leakage. Retain inspected captures/interaction
  evidence. Check suffix warning and terminology persistence end to end.
- Run full mandatory ruff → mypy → pytest chain and rerun affected acceptance after fixes.

## Verification Notes

Native resources, independently judged references and optional private data are
explicit prerequisites, not assumed present. Bind evidence to exact revisions.
Synthetic fixtures cannot prove the reported collection yield; record limits honestly.
