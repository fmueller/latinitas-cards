# T-200-evaluate-held-out-automatic-acceptance-against Evaluate held-out automatic acceptance against independent judgments

## Description

P50-7 evaluator owns empirical prerequisites and held-out evidence under the approved
forward method. Follow docs/v0.5.0-evaluation-plan.md and the spec's isolation/final
checks. The stages below are ordered gates inside this task, not permission for
judges/research or a successor to an exhausted allocation. No automatic policy is
enabled merely by starting or completing an evaluation.

## Acceptance

- Before held-out sampling/exposure, record permitted acquisition/rights and actual
  independently qualified reference/adjudicator appointments for each scope/language.
  Preserve source-grounded solving, citation entailment, abstentions, actual exposure
  and shared-dependency limitations; role names or agreement cannot qualify judges.
- Then establish protected custody and development-only output feasibility for the
  proposed frozen allocation, using separately authorized work. Preserve raw failures
  and exact commitments; an exhausted failed study cannot be reopened/repaired.
- Then obtain explicit maintainer acceptance of exact candidate policy/checker/support
  registry, strata, justified minimum samples/accepted counts, error/coverage criteria,
  uncertainty and stopping rules. Freeze before drawing/opening protected holdout.
  Missing acquisition, qualification, feasibility or criteria stops the dependent
  phase; an implementation-ready task graph does not satisfy these gates.
- Run frozen held-out samples without tuning on answers. Record exact code/data/
  policy/analyzer/model/checker revisions, strata, counts, adjudication and denominators
  for errors, precision, coverage, withholdings and failures. Include counterexamples
  and classical/biblical/varied materials. Obtain separate run authorization; use
  isolated would-accept artifacts without ordinary learning export authority.
- Compare measurements to approved sample sizes/thresholds. Model agreement/confidence
  is not reference truth. Zero acceptance is not evaluable; inadequate samples or
  missing independent judgments cannot pass.
- Report coverage limits and failed/inconclusive strata. Block affected automatic paths;
  narrowing/disabling requires maintainer disposition and refreshed affected review/
  evidence, never silent threshold adjustment or claiming original scope passed.
- Preserve human/automatic distinction, reliability over yield and no uncertain-card
  learning deck to inflate counts.
- Independently audit the report and record separate maintainer enablement against
  exact evidence/policy/registry entries before any production automatic learning
  export. A pass does not enable itself; insufficient/failed strata remain disabled.
  Completing with reduced automatic scope requires an explicit maintainer amendment
  and refreshed affected evidence, never a silently narrower v0.5.0 claim.

## Verification Notes

adjudication and calculations. Repeat a measured slice only within its prospectively
authorized allocation; demonstrate zero-acceptance and missing-prerequisite stops.
Readiness requires approved criteria, supporting evidence and explicit enablement or
an explicitly revised approved scope, not mocked results. Preserve historical protocol
and study hashes/results; this task has no implicit new-study authorization.
