# T-003-principal-part-card-generation Generate principal-part study cards

## Description

Generate the first deck-enrichment recipes from confirmed lexical entries: Latin-first
principal-part completion and principal-part recognition. Preserve named semantic roles and
the relationship to the source entry, include the configured German gloss, and report
ambiguous or incomplete entries rather than guessing.

## Acceptance

- Completion cards omit one named principal part and answer with the missing form and role.
- Recognition cards map a supplied principal part to its lemma, complete principal parts,
  role/stem, and configured German gloss.
- Generated exercises use the stable identity and generated-note contract from T-002.
- Each exercise is an independent note/card by default and retains source provenance.
- German-to-Latin production is not generated by these recipes.
- Incomplete, unsupported, and ambiguous entries are skipped with structured reasons.
- Recipe selection comes from the confirmed profile and does not enable every compatible
  exercise implicitly.
- Local fixtures cover regular entries, varying separators, missing parts, ambiguity, and
  stable regeneration.
- Implement with red/green TDD in focused modules rather than expanding `cli.py`.
- `uv run ruff check`, `uv run mypy`, and `uv run pytest -v` pass.
