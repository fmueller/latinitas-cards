# T-206-design-deck-workflow-follow-up-contracts Design deck workflow follow-up contracts

## Description

Draft shared contracts for FR-1 through FR-8 against approved v0.5.0 interfaces.
Own profile/role, extraction, review, presentation and checkpoint proposals, not
policy approval or consumer implementation. This inactive package needs separate
approval/activation before execution.

## Acceptance

- Define mixed verb/nominal class routing, number-aware plural-only roles,
  adjective terminations, recipes/terminology and opt-in layout migration without
  renumbering verb ordinals or changing old-profile output.
- Define evidence reference schema/rights and calibration applicability, sample
  decisions, independently judged held-out evaluation and measured pass criteria.
  Bound investigation to a candidate inventory and one evaluation design; missing
  rights/data or inconclusive results block calibration, not fabricate support.
- Freeze review CSV schema/encoding, formula escaping with canonical bindings,
  verdict mapping, default audit reason, atomic validation and idempotence.
  Define parsing policies, preserved alternatives and complete JSON/table skips.
- Approved expanded FR-4 amendment: define lexical/principal-field annotation
  boundaries that preserve meaningful parentheses/alternatives, distinct compound
  pipe versus pipe-alternative policies, German deponent/semi-deponent roles and
  display versus canonical answer-equivalence representations. Verify the actual
  answer surface; current reveal-only templates do not imply typed grading.
  Resolve any typing/grading requirement explicitly before consumers.
- Define per-source-note report aggregation and primary-code precedence, related
  reasons/fragments, confirmed tag scope and full JSON/table/CSV output. Distinguish
  unchanged-policy baseline counts from recovered/residual post-fix outcomes.
- Define confirmed source-stream authority/continuity (GUID overlap is insufficient),
  checkpoint location/override precedence, atomic migration and valid review-state
  discovery/reattachment through approved decision adapters, never a second store.
- Define canonical reference output/CSS comparison, persisted terminology provenance
  and JSON suffix warnings. Calibration withdrawal consumes T-195 receipts/handoff;
  CSV omission is not installed-content resolution.
- Supply valid/invalid payloads, compatibility fixtures, shared-module ownership,
  exact contract revisions and remaining maintainer decisions before consumers.

## Verification Notes

review proposals/examples. Follow the full spec's compatibility, evidence and
permission boundaries. No private source access, network calls or publication.
