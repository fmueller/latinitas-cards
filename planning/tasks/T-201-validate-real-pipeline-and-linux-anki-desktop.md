# T-201-validate-real-pipeline-and-linux-anki-desktop Validate real pipeline and Linux Anki Desktop journeys

## Description

P50-7 integration owner executes native kit and real-stack scenarios on the evaluated
candidate. Requires Linux Anki Desktop, supported library resources and explicitly
authorized local/hosted endpoints with permitted data. Missing resources/permission
blocks evidence. Use disposable data/profile; follow spec execution/validation rules.

## Acceptance

- Run real library/model forms/phrases, LLM-off/no-network, hostile text boundaries,
  interrupted/unknown-call reconciliation/resume and binding invalidation. Record
  effective endpoints, request scope/permission, versions and limits without secrets.
  No fallback or repeated valid calls.
- Exercise more-than-20 full output, optional batch reuse, every report outcome,
  German/English and curated rule/rendered approvals, plus approval of any mnemonic
  shown, with affected renewal after edits. Include rule-only export/import when no
  mnemonic exists and English rule-only cards when only a German mnemonic is approved.
- In native Desktop import/update mixed human/automatic cards. Inspect light/dark,
  collapsed/expanded evidence, actual keyboard/pointer and no front leakage. Preserve
  personal fields/tags, identities and conservative status summaries.
- Invalidate installed source/checker evidence or policy and withdraw curated approval;
  regenerate and execute the supported retained-field or manual-resolution path.
  New exports cannot assert old acceptance; no unintended scheduling/history changes.
  CSV omission is not retirement.
- Bind screenshots/clips, before/after identities and limitations to candidate/data/
  artifact revisions. No Mobile/existing scheduled-collection claim; previews/mocks
  cannot replace native/library/provider evidence.

## Verification Notes

Use independent expected results from kit/protocol. Run the full mandatory ruff/mypy/
pytest chain before verify/complete. Name any unavailable environment as a blocker.
No publication permission is granted.
