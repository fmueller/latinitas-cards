byte goldens generated by current `main` that later tasks must keep unchanged. This task
changes nothing under `src/`. Reuse the existing golden harness pattern
(`tests/fixtures/goldens/*/cases.json`, `scripts/regen-legacy-goldens.py`, the CAPTURE
manifest checked by `golden_manifest_test.py`, fixed `COLUMNS`/`TZ`/locale environment).

Fixed Contracts in `specs/v0.4.0.md` are binding and take precedence over this note; file a blocked follow-up task instead of amending them. Run the mandatory `uv run ruff check`, `uv run mypy`, `uv run pytest -v` chain before verify/complete.

  `principal_part_completion`/`principal_part_recognition` (with reviewed form
  translations, `user` and `latin` terminology, `light`/`dark`/`auto`), phrase
  translation/recognition and form parsing, including one profile whose `language_tag`
  is neither `de` nor `en` with Latin terminology.

  (manifest and `--citation-template` paths), plus their `corpus validate --json`.

  manifest records the capture commit.
- `git diff --stat -- src/` is empty for this task.
